# Motionbench：把動態交付變成可以檢查的參數

版本：0.1.0。此版本涵蓋單一物件的位移曲線、參數比較與程式碼交付。

## 問題與使用情境

設計交付常把動態描述成「再彈一點」「收得快一點」。這些描述有方向，卻沒有明確的重現方式。Motionbench 把討論落在三個可檢查的輸出：位置對時間的曲線、實際移動物件，以及可匯出的程式碼。

這個作品的範圍是單一自由度的進場位移。它不取代完整動畫工具，也不把彈簧產生器當成新的演算法。重點是參數與結果對得上，讓檢視者能調整、比較、帶走結果。

## 模型與資料流

彈簧使用質量、阻尼與剛度的解析解：

```text
m x'' + c x' + k (x − 1) = 0
x(0) = 0, x'(0) = 0
ζ = c / (2 √(km))
```

- `ζ < 1`：欠阻尼，用指數衰減與三角函數描述超越和回彈。
- `ζ = 1`：臨界阻尼，使用獨立公式，避免一般公式在分母趨近零時失去穩定性。程式對 `|ζ−1| < 10⁻⁵` 使用此近似。
- `ζ > 1`：過阻尼，使用兩個實根的指數形式；較慢的根用倒數形式計算，降低大數相減造成的誤差，也避免雙曲函數溢位。

穩定時間以每秒 120 次檢查：位置誤差小於 0.001、前向差分速度小於 0.01，並維持 200 毫秒。這是明確的工程門檻，不是「永遠不再移動」的數學宣稱。12 秒上限可避免匯出無限等待的動畫；超過時介面會顯示警示。

貝茲曲線不能直接把參數 `t` 當成時間。`bezierAt` 先以 32 次二分搜尋反解單調的 X，再取 Y。X 控制點限制在 0–1，以符合 CSS 的時間軸條件；Y 可低於 0 或高於 1，保留預備動作與超越效果。

```text
參數 → 解析解／貝茲反解 → 181 個位置樣本
                            ├─ 曲線與預覽播放
                            ├─ CSS linear()（彈簧）
                            └─ Web Animations keyframes（JavaScript）

貝茲參數 ────────────────────→ CSS cubic-bezier()（原生精確曲線）
```

樣本的時間必須嚴格遞增，起點為 `(0, 0)`，終點為 `(1, 1)`。`linear()` 的位置值可以大於 1，否則會錯誤截掉超越效果。彈簧和 JavaScript 匯出都是分段線性近似；UI 播放也用相同樣本插值，避免預覽和匯出各自實作一套行為。

## 介面與取捨

版面從左側的觀察，連到右側的調整，再連到下方的匯出。圖上同時提供座標、穩定時間、超越幅度與阻尼狀態；滑桿旁有可直接輸入的數值。

「固定並比較」保留一條虛線參考。比較採正規化時間：不同長度的曲線都在 0–100% 區間顯示。這讓形狀容易比較，但不能用圖上同一水平位置推論兩者已經過相同毫秒；因此介面明示此規則，並保留參考的原始時長。

動畫採 `requestAnimationFrame`，失去頁籤可見性時暫停推進時間。曲線計算與匯出使用 memoization，參數未改變時不重算主曲線。181 個取樣點是尺寸、可讀性與精度的折衷，沒有宣稱在所有高頻或極端物理參數下都能精確重現連續系統。

## 可及性與錯誤處理

控制項使用原生按鈕、range、number、checkbox；數值輸入會檢查界限，錯誤會設定 `aria-invalid`。鍵盤焦點可見，圖表有文字摘要，切換語言時同步更新文件語言。

偵測到 `prefers-reduced-motion: reduce` 時，預覽直接停在終點，重播與循環控制停用；偏好即時變更也會生效。CSS 匯出包含對應 media query，JavaScript 匯出在每次啟動時檢查偏好。它沒有監看匯出後正在執行的 JavaScript 動畫；呼叫端可透過回傳的 `Animation` 取消。

剪貼簿寫入與檔案下載分開處理。寫入失敗會顯示錯誤並指向下載，不會假裝「已複製」。程式碼也可展開直接選取。沒有外部字型、分析追蹤或遠端服務要求。

這些是實作層面的可及性設計，並非完整 WCAG 稽核或輔助科技認證。
